Enter or resume the analyst loop (agents/analyst.md). Open with the
banner, then on resume a 3-line French summary: found / hypotheses / missing -
and hand back to the analyst.

For a question or hypothesis: DFIQ questions (official or internal) ->
approaches -> required artifacts -> coverage check. Missing from the
collection -> gap; encrypted without key -> gap `key_required` (next action is
/key add); present but unextracted -> /extract; present -> catalogue hunt with
params, free SQL only if none fits. Propose leads with citations, call the
reviewer before any promotion, journal, rewrite the current-state block, ask
for validation.
