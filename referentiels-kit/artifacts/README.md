# Artefacts custom kit - referentiels-kit/artifacts/

Definitions d'artefacts ecrites par le kit, au format ForensicArtifacts
(`sources`, `conditions`, `supported_os`). Chargees par `scripts/referentiels.py`
en complement de l'amont bake dans l'image (`/referentiels/artifacts/data`).

Nommer les artefacts kit avec le suffixe `Kit` pour eviter toute collision amont
(ex. `EriInternalLogsKit`). Voir `../README.md` pour les regles completes.
