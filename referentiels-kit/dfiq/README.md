# DFIQ kit - referentiels-kit/dfiq/

Scenarios, facets, questions et approches ecrits par le kit, au format DFIQ
(`id`, `name`, `parent_ids`, `approaches`). Charges par `scripts/referentiels.py`
en complement de l'amont bake dans l'image (`/referentiels/dfiq/data`).

Prefixer les id kit par `SK` (ex. `SK1001`) pour eviter toute collision avec
l'amont (S/F/Q). Voir `../README.md` pour les regles completes.
